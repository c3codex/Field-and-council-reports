# ✦ Codexstone Docs ✦  

This folder preserves the **living documentation** of the c3 Codex.

---

## Structure
- **/reports/** → Council & field reports (time-stamped by date)  
- **/supplements/** → Additional material (appendices, commentary, witness protocols)  
- **/glossary/** → Future integration of Codexstone glossary  

Each entry is a **living record**: breath, presence, decision, and resonance.
